# Логотип «Хроники»

**Идея:** дом, у которого правый скат крыши спускается ступенями, как цена в истории квартиры. Это ровно то, что показывает «Хроника» и чего не видно на самих площадках.

Готовые файлы лежат в [final/](final/), доска с макетами — в [presentation.html](presentation.html) (слайды: [slides/](slides/)), первый раунд концептов — в [concepts/](concepts/).

| Нужно | Файл |
|---|---|

## Цвет

Один цвет, тот же, что в кабинете (DESIGN.md, «One Spot Rule»).

| | HEX | RGB |
|---|---|---|
| Печатный синий (основной) | `#1c3dbf` | 28 61 191 |
| Белый (на синем) | `#ffffff` | 255 255 255 |
| Чёрная краска (одноцветная печать) | `#15171b` | 21 23 27 |

Белый на синем имеет контраст около 8:1 (WCAG AAA). Красный в логотипе не используется: в кабинете красный означает только снижение цены.

## Правила

- **Свободное поле** вокруг логотипа — не меньше ширины двери (⅕ ширины знака) с каждой стороны.
- **Минимальный размер:** знак — 16 px (до 32 px берите `symbol-small`), горизонтальный логотип — 96 px в ширину.
- **Фон:** синий логотип ставится на белый и на бумагу `#eceef0`, белый — на синий `#1c3dbf` и на тёмные фото. Синий на тёмном не ставить.
- **Нельзя:** растягивать и наклонять, менять ступени местами или зеркалить дом, добавлять тени, обводки и градиенты, перекрашивать в другие цвета, набирать «Хронику» другим шрифтом рядом со знаком.

## Шрифт и исходники

Название набрано PT Sans Narrow Bold (лицензия OFL, логотип разрешён) и переведено в кривые, поэтому шрифт для файлов не нужен. Мастер-файлы пересобираются скриптом `build_logo.py`. Ему нужны `fonttools` и `brotli`:

```
pip install fonttools brotli
python docs/brand/logo/build_logo.py
```

Иконки и варианты сделаны скриптами скилла logo-design (`export_variants.py`, `render_png.py`).

## Что не проверено

- Проверка товарных знаков не проводилась. Перед регистрацией бренда стоит поискать похожие знаки в реестре НЦИС и через поиск по картинкам.
- Pantone и CMYK не подбирались. Для типографской печати цвет нужно подобрать по веерам.
