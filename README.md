# Хроника

Telegram-бот, который помогает купить квартиру в Минске без агентства: ищет по всем четырём площадкам сразу (Kufar, Realt, Onliner, Domovita), показывает каждую квартиру один раз и честно говорит, стоит ли её смотреть.

## Какую проблему решает

Чтобы найти квартиру, покупатель смотрит 4 сайта и видит одну и ту же квартиру по 3–5 раз от разных агентств. Понять, дорого это или нет, нельзя: площадки показывают только сегодняшний снимок. Когда объявление перевыкладывают, счётчик «дней на рынке» обнуляется, а история снижений цены пропадает. Можно заплатить агентству, но тогда за сведение всего вместе платит сам покупатель.

## Что делает бот

1. **Ищет квартиру по всем площадкам сразу.** Человек кнопками задаёт бюджет, комнаты, район, площадь и, если хочет, «новостройка / вторичка» и этаж. Бот присылает квартиры, где **каждая квартира показана один раз**, даже если её продают пять агентств. Сначала идут выгодные, можно отсортировать по цене или по свежести.
2. **Говорит, стоит ли смотреть.** Бот сравнивает цену за м² с похожими квартирами рядом (те же комнаты, похожий возраст дома, отделка) и пишет вывод: «стоит смотреть», «цена в рынке», «дороже похожих» или «подозрительно дёшево — узнайте причину».
3. **Показывает историю, которой нет на сайтах.** Сколько квартира на самом деле продаётся с учётом перевыкладываний, сколько раз дешевела, на каких площадках выставлена, собственник продаёт или агентство.
4. **Выписывает важное из описания продавца.** Торг, ипотека, рассрочка, мебель, а тревожное идёт первым: продаётся доля, прописаны люди, только наличные. Плюс детали: кухня, санузел, балкон, потолки.
5. **Следит за выбранными квартирами.** Сообщает, если квартира подешевела, её сняли с продажи или выставили заново.

Проверить отдельное объявление тоже можно: прислать боту ссылку на него с любой из четырёх площадок.

## Чем бот не является

- **Не уведомлялка о новых объявлениях.** Таких ботов много, и там решает скорость. Ценность «Хроники» в честной истории и оценке квартиры, а не в том, чтобы прислать объявление первым.
- **Не хранит чужие фото и персональные данные.** Телефонов и имён продавцов в базе нет, текст описаний не сохраняется, только найденные в нём факты. Фото в карточке — это обычное превью ссылки площадки.
- **Не продаёт данные площадок.** Только выводы.

## Для кого

Покупатель квартиры в Минске, который не хочет платить агентству или ищет издалека (для родителей, из-за границы). Позже — риелтор покупателя, которому нужны аргументы для торга.

## Для разработчика

Правила проекта для Claude: [.claude/skills/minsk-realty/SKILL.md](.claude/skills/minsk-realty/SKILL.md).
Агенты: [.claude/agents/](.claude/agents/) — Sam (сбор), Emma (склейка), Leo (аналитика), Mia (бот), Grant (контроль).

Всё работает в Docker Compose на домашнем компьютере в Беларуси: `db` (PostgreSQL), `migrate`, `collector` (сборщик), `web` (кабинет), `bot` (Telegram-бот), `backup` (ежедневный бэкап).

### Кабинет

Локальный веб-кабинет для владельца: `python -m minsk_realty.web` → http://localhost:8080 (в docker compose — сервис `web`). Наружу без пароля не открывается.
Посмотреть на вымышленных данных: `python scripts/demo_db.py demo.db`, затем `DATABASE_URL=sqlite:///demo.db python -m minsk_realty.web`.

### Telegram-бот

`TELEGRAM_BOT_TOKEN=… python -m minsk_realty.bot` (в docker compose — сервис `bot`; настройка — [docs/setup-home-computer.md](docs/setup-home-computer.md), шаг 9).
Команды: `/search` — поиск квартир, ссылка на объявление или `/check` — отчёт, `/list` — «Мои квартиры», `/forget` — удалить свои данные.

### Разработка

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
pytest            # тесты без сети
ruff check .
```

### Запуск сборщика

Kufar не отвечает на запросы не из Беларуси, поэтому сборщик работает на сервере или домашнем компьютере в Беларуси.
Пошагово для домашнего компьютера: [docs/setup-home-computer.md](docs/setup-home-computer.md).

```bash
cp .env.example .env        # заполнить POSTGRES_PASSWORD и SELLER_KEY_SALT
docker compose up -d --build
docker compose logs -f collector
```

Сборщик обходит Kufar, Realt и Onliner раз в 30–60 минут, Domovita — раз в 6 часов, и записывает изменения объявлений.
Если площадка перестаёт отдавать данные, он присылает алерт в Telegram (`TELEGRAM_BOT_TOKEN`, `ADMIN_CHAT_ID`), не чаще раза в сутки на одну проблему.
После ответов 403/429 площадка останавливается. Запустить её снова после проверки причины:
`docker compose run --rm collector python -m minsk_realty.collector --once --unblock kufar`.
Первые живые фикстуры (сохранятся в `tests/fixtures/` на сервере):
`docker compose run --rm --user "$(id -u):$(id -g)" -v "$PWD/tests/fixtures:/app/tests/fixtures" collector python scripts/capture_fixture.py kufar`
